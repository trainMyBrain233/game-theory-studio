# 视觉研究：来源与借鉴边界

研究日期：2026-10-08。以下是公开页面与视频关键片段的设计观察，不是全文转录、全片评测或平台整体趋势。色值是本项目自拟，未宣称为原作者品牌色。

当前采用B「清爽教材」：一个具体情境与一张持续演进的图。颜色用于知识语义，保留留白、稳定锚点与连续推导。

## 核心参考

1. [柴知道：《“博弈论”是怎样的学问？》](https://www.bilibili.com/video/BV1sx411x7Yb/)
   - 抽看约00:55、01:09、02:51。近白底、细线人物与收益矩阵共同说明同一个问题，后续切换到两车情境。
   - 借鉴：人物、策略与表格指向同一问题，矩阵逐步展开。
   - 不复刻角色和原画；放大矩阵与文字，避免过淡线条和手机上过小的表格。
2. [李永乐老师官方：纳什均衡理论](https://www.bilibili.com/video/BV16s41177fZ/)
   - 抽看约00:30、01:00、02:57。同一张黑板收益表持续增加信息，讲解顺序建立层次。
   - 借鉴：固定矩阵位置、补数、比较、标注；不需要照搬绿色黑板、教室透视或遮挡。

## 补充与边界对照

3. [一图研究所：一根头发，究竟是怎么“死”掉的？](https://www.xiaohongshu.com/explore/6a8f7ea0000000002a03e111)
   - 观察第一张「头发的一生」信息图：暖白底、墨黑标题、一个横向主图与细线阶段分区。这是图文，不是视频参考。
   - 借鉴主图与标题层次；不把五列小字长图整张塞入视频，不据此判断健康内容准确性。
4. [科思妙想者：卷发是如何形成的](https://www.xiaohongshu.com/explore/6aa43ba3000000000b00e0d9)
   - 观察开头单根毛发与后续毛囊剖面；未观看全片，未核实动画原创归属。
   - 借鉴一镜一个机制，以及颜色来自被解释的对象；不借3D皮肤材质或粉棕配色。
5. [混乱博物馆：色彩的空间（转载观看页）](https://www.bilibili.com/video/BV18P411C7sv/)
   - 页面为转载，不能当成已核实官方原作链接。观察固定外框与中心色空间图示。
   - 借鉴轻量系列标识与语义配色，不把彩虹渐变无理由放入收益表。
6. [柴知道：2025年了，手游渠道服为何还不互通？](https://www.bilibili.com/video/BV1d1bEzvEXc/)
   - 抽看约01:49及后续平台互通图示，深底、界面、粉色强调与发光轮廓。
   - 这是边界对照：真实界面是其讲解对象，但本系列采用浅底教材风，不跟随深底发光外观。
