# 博弈论教学内容检查单

适用范围：每章脚本、字幕、示意图和原速片段的内容复核。四问是本系列的入门整理方式；以下检查不要求第一章补讲均衡、概率或重复博弈。本轮只改 s33 的“节省的时间”和画面“省下的时间”，其他深化建议待有具体误解证据再处理。

1. **说明模型假设。** 能指出谁决策、可选行动、行动时序、决策时可用信息及结果/收益。把教学案例的“一轮、各自追求较高得分”等假设写明，不能称为所有博弈或所有人的共同事实。四问不是唯一正式分类。[Yale 第2讲](https://oyc.yale.edu/economics/econ-159/lecture-2)、[MIT 广义式博弈](https://ocw.mit.edu/courses/17-810-game-theory-spring-2021/mit17_810s21_lec4.pdf)。
2. **区分行动与策略。** 单次决策可直接以两种行动表示纯策略；一般策略应给出在各个可能决策情境中依据可用信息采取什么行动。多轮示例明确标为概念比较，结束后回到本章模型，不暗示已分析重复博弈。[MIT 第4讲，第11页](https://ocw.mit.edu/courses/17-810-game-theory-spring-2021/mit17_810s21_lec4.pdf#page=11)。
3. **区分信息概念。** 看不到对手本轮行动不等于不知道类型、规则或收益。同时行动表示决策时未观察对手当前选择，不能用两段动画恰好同秒播放作为定义。[MIT 第4讲，第2页](https://ocw.mit.edu/courses/17-810-game-theory-spring-2021/mit17_810s21_lec4.pdf#page=2)。
4. **说明收益的意义和方向。** 标清数字代表什么、较大是否较好。若以成本或时间表示而仍称“越高越好”，须转换为负成本、节省的时间或明确偏好；不直接跨人相加效用，不把模型中的自利假设泛化为人的本性。[Yale 第1讲](https://oyc.yale.edu/economics/econ-159/lecture-1)、[MIT 第1讲，第56–59页](https://ocw.mit.edu/courses/17-810-game-theory-spring-2021/mit17_810s21_lec1.pdf#page=56)。
5. **逐格核对矩阵。** 明确行、列的参与者、策略数和每格数对顺序。至少用一格不对称收益核对字幕、口播、文字、箭头和高亮的玩家归属；不能因对称格数字相同就推断全部正确。工程中 A 为行、B 为列，数对 A 在前。
6. **分开描述、比较与预测。** 描述博弈、比较收益、预测选择各需自己的依据。若后续讲均衡，说明谁在其他人不变时可以单方改变什么；概率标明所属玩家或事件；推理使用可见假设，角色表情不能替代论证。
7. **给完整理解窗口。** 按完整句/语义块检查实际显示窗、尾停与稳定图形；数字比较期间减少无关移动。字符/秒和TTS预听只是筛查工具，静音阅读与真人口播试听分别记录，不能互相替代。
8. **记录新手复述。** 让未看脚本者复述一个概念，并读一个未提前讲解的格子或分支；记录错误对应段落/时点。影响答案、身份或概念理解的缺陷必须修，扩展深度和措辞偏好需给具体证据再安排。

交付时分别填写：脚本文字已核对、关键帧已看、真实录音对齐已做/未做、新手原速观看已做/未做。自动测试通过只能支持其覆盖范围，不能把后两项自动勾选。制作尺度和音频/平台验收见[制作指南](production-guide/video-production-guide.zh-CN.md)与[逐集验收模板](production-guide/episode-acceptance-template.zh-CN.md)。
