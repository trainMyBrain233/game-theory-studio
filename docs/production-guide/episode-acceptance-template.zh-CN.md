# 博弈论视频逐集验收

每集复制一份。本表补充工程现有测试；未实际检查的项保持未勾选。未选择配音交付时，不以“没有人声”判本阶段失败，但不得写成已配音正片。

## 十项放行检查

1. [ ] **内容与身份一致**。抽查每个收益数对、行列、角色和策略；每次揭示均对应当前选择。让未看脚本的人回答本集核心问题；记录说不清或误解的时间点。证据：具体帧或反馈。
2. [ ] **字幕文字与时间可信**。检查简中字形、真实400/700、语义断行、标点禁则、数字/姓名不拆散；统计逐块字符/秒与完整可见时间。真人配音版须根据最终录音校正，ASR结果需人工听回。证据：字幕版本、超限复核、录音版本；无配音时明确 N/A。
3. [ ] **目标屏幕能读**。至少检查一张最长双行字幕＋完整矩阵帧的原生1080p和合理手机横屏缩放，再看360px小窗作为诊断。真实平台UI/弹幕有无遮挡单独记录，没测不能写“通过”。证据：尺寸、时间点、设备/客户端、结果。
4. [ ] **一段一个推理重点**。新定义、矩阵比较、字幕阅读和角色动作不同时争夺注意；定义与数值揭示后有足够理解窗。保留字幕无障碍用途，删减重复的画面长文。证据：密度最高的两处片段及新手复述结果。
5. [ ] **动作和转场连续**。角色身份、手牌、持牌位置与矩阵标记前后一致；检查起止附近及中间帧，原速看有无瞬移、重复牌、文字淡入叠影、关节接缝。长移动不机械套0.3秒。证据：转场片段或帧号。
6. [ ] **角色与图形清晰**。1080p/4K分开检查；记录角色各层的最大屏幕尺寸与源像素尺寸，放大过多有目视说明；白底无黑边/白晕、蒙版切口和层间裂缝。4K不能仅由成片放大。证据：实际生产角色帧，不能用占位替代。
7. [ ] **音频符合本次状态**。无音轨按无声交付；SFX-only检查舒适、无爆音，不为凑LUFS拉响；配音版检查清晰度、真峰、最终AAC解码后的峰值、音乐/SFX避让与单声道兼容。证据：测量值和原速完整试听；目标LUFS注明来源或项目暂定。
8. [ ] **重定时没有遗留旧事件**。字幕、动作、得分、SFX和转场来自相同版本事件；修改一句话后复查其后全片，不只看改动附近。证据：事件差异、音频/字幕/视频版本绑定；不保留无人核验的绝对秒数。
9. [ ] **成片与平台转码均复核**。完整解码并核验尺寸、帧率、帧数、视频/音频起点与时长、SAR、范围/颜色标记；编码后检查文字边缘和浅底。平台上传需另有授权，高清处理完成后检查网页及手机播放。证据：本地报告＋平台检查记录；未上传则后半项“待验”。
10. [ ] **发布范围与素材来源清楚**。核对角色取得方式、音乐/音效/字体许可、必要非关联声明；公开源码不含私有素材与相关预览。未核实B站当前规格或素材用途时写明待核验，不能以“已放私有目录”替代权利审查。证据：来源登记、投稿规格核验日期、公开包扫描结果。
