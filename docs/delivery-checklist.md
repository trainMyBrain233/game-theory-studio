# 交付检查单

每次交付在 PR 中给出当前 commit、环境、命令结果和未覆盖项。下面的机器检查与人工检查都要有实际证据；未完成的项目保留未勾选。

## 工程基础

- [ ] 从 lockfile 干净安装；固定版本 requirements 安装到项目 `.venv`。
- [ ] 官方/明确本地字体准备成功；4 个完整 SC face、400/700、版本/字形/校验值检查通过。
- [ ] 场景、tokens、所有章节元数据/timeline 的 Schema 与语义通过。
- [ ] 字幕/口播产物临时重建逐字节一致；被检查文件没有被 QA 写回。
- [ ] 核心负向测试通过：错玩家/收益/选择、重复尾停、过期字幕、非 UTF-8 locale、失败生成和字体恢复。
- [ ] 6 张原创静帧、3 张对照板；53 项基础检查包含真实选择高亮/说明，15 个状态通过测量边界与文字碰撞。
- [ ] 12 个变异矩阵、4 种选牌、48px/宋体配置改变实际像素；原创几何 0/0.5/1s 重复帧确定性通过。
- [ ] 本机看过 B 模板和 SC 字形板；新增文字/角色看过实际净空和缩小可读性。
- [ ] 原创归档 SVG/标签 mask 净空通过；没有把它们当成最终 PvZ 角色。
- [ ] `qa:source`、暂存 diff、许可证边界检查完成；无 EA 位图、字体二进制、视频、秘密或私有绝对路径。
- [ ] 草稿 PR 的当前 head 对应 Linux/macOS Quality 两项 CI 成功；没有强推、合并或改权限。

## 完整影片（当前基础工程不能替代）

- [ ] 有实际音轨，并按语义、换气、数字重音对齐字幕/画面。
- [ ] 全时段场景、角色动作/表情、素材来源与权限说明齐全；仓库外生产素材没有误混入公开 MIT 源码。
- [ ] 每个转场检查起点、25%、50%、75%、终点与相邻帧，字幕在完整阅读窗内稳定可见。
- [ ] 原生输出和编码后抽帧检查字形、字号、数对、高亮、图文净空和压缩边缘。
- [ ] 完整试听、片尾留白、平台播放效果和最终 duration/fps/尺寸检查通过。

原型可交付与正片完成是不同里程碑。没有实际整片和音频证据时，状态继续标注“原型 / 人工口播参考 / 未音频对齐”。
