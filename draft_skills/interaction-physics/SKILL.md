# 手与道具交互

本文件是待审核草稿。以当前项目合同和目标镜头为准。先明确“人物正在做什么、道具此刻由什么支撑”，再设计动画；不为了用某个开源框架改写现有渲染器。

## 必要输入

读取角色能力、每个手姿的透明素材、前臂/袖口层、牌形状与文字、桌面/牌架几何、动作语义锚点。记录素材版本，不从上一版批准推断新版也合格。原图缺少所需握姿时先报告并准备候选，不用拉伸烘焙手指冒充开合。

当前实现入口通常为 `character-layers.mjs`、`rgba_character_rig.mjs`、`choreography.mjs`、`card-transform.mjs` 与 `tests/attachments.test.mjs`。保持既有固定骨长、可达范围和支付语义检查。

## 腕点和抓握点不是一个点

- 每个手姿定义腕pivot，位置按实际解剖/袖口连接标定，不能由透明画布中心或包围盒中心推测。
- 单独定义grip anchor、握持方向，以及前指/后掌的遮挡层。局部点的空间与像素单位写清楚。
- 替换手姿先在统一腕坐标注册；必要时使用中间手姿或有依据的遮挡切换，不让两只半透明手长时间叠在一起。
- 袖口、前臂和手的轮廓接缝必须实看。数值腕点不漂移只证明坐标正确。
- 调试可显示骨骼和锚点，交付图不可带调试标记。

## 支撑状态决定道具运动

为道具定义明确阶段，至少覆盖桌面/牌架、接近、接触交接、手持、落放交接、释放。自由飞行只有剧情明确需要时才有，不能成为状态空档的默认解释。

桌面支撑时保持约定接触关系；手持时由手—牌的固定相对变换决定；交接时两种约束在同一姿态相容，然后转移控制。不要让牌和手分别跑两条相近曲线，再把“看起来大概重合”当作绑定。

先确定牌是平放、竖持还是被牌架托住。牌面朝向、可见厚度、桌沿、接触阴影与这个设定一致。阴影不能单独证明有支撑。

根据真实姿势确定遮挡顺序，例如后掌/拇指、牌、前指；检查可见指尖是否跨过牌缘形成夹持。整臂统一最后绘制可能错误遮挡桌沿或牌，不能只用单一全局z序解决全部姿态。

## 节奏与连续性

用完整动作短段检查：接近 → 接触 → 抬起 → 持稳 → 放下 → 松开 → 撤手。静态夹持轻摆不能覆盖取放。

为动作引用命名语义事件，再编译成显式时间函数。停顿用于让观众辨认动作；接触期间禁止缓动过冲破坏绑定。自然感来自合理轨迹、速度变化、停顿与轮廓，不靠随机抖动补救。

首集“两人各自决定再共同揭示”的语义保持同步。允许轻微表演差异，但不能让一方提前看见对方选择或把同时博弈变成先后观察决策。

## 分开出具三种结果

1. **几何结果：**骨长、可达性、腕点注册、grip误差、交接连续性、画面边界。沿用已批准的项目阈值；若提出如1080p下2px的新阈值，明确它是待视觉标定的工程建议，按输出比例换算，不称行业标准。
2. **像素结果：**袖口缝隙、前后指覆盖、牌中文字、桌沿遮挡、实际alpha轮廓。用最终素材和最终渲染变换，不能只查计划坐标。
3. **观感结果：**正常速度和慢放，手是握住、托住、碰到还是像挂牌；牌有重量感与支撑，动作读得懂。没有实看则未验证。

优先加入与本次修改对应的破坏性夹具：腕pivot偏移、错误图框注册、删除前指层、释放后撤掉桌面约束、绑定期让牌独立偏移。保证测试真的拒绝错误，而非重新计算同一声明并相互印证。

短段至少采动作关键状态、交接前后相邻帧和运动区间中间帧。发现问题先定位美术、锚点、支撑或时间控制中的哪一层，修该层；不未经审阅全片渲染。

## 借鉴与不兼容项

本文的腕点/支撑/像素分层规则是面向本项目的原创合同，不宣称开源skill已解决自然握姿。

- [Motion Canvas positioning](https://motioncanvas.io/docs/positioning/) 与 [Node.ts](https://github.com/motion-canvas/motion-canvas/blob/7b91435c301d530351dcf5ebb91dd139c002e405/packages/2d/src/lib/components/Node.ts)：借鉴坐标空间与相对关系；不移植其坐标原点或运行时。
- [Remotion timing](https://github.com/remotion-dev/skills/blob/32b241b97f4e0e4ab61fe9a41b05e6e64503f8c5/skills/remotion-markup/timing.md)：仅参考显式帧与插值限界；Spring不能保证物理接触。不复制该许可尚未核实仓库的文本或脚本。
- [OpenAI视觉QA](https://github.com/openai/skills/blob/49f948faa9258a0c61caceaf225e179651397431/skills/.curated/playwright-interactive/SKILL.md#L306-L342)：借鉴数值与可见质量分别验收；不安装浏览器或改变权限。
