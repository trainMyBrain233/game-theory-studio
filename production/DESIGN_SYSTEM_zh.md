# 清爽教材风：制作与复用规范

## 范式状态

B风格已确定。私有生产方向采用普通僵尸A、路障僵尸B的高清RGBA分层角色，字幕讲解称为小A、小B。角色是位图层，卡牌、图表、身份徽记和中文文字为可编辑矢量/文字；不可把本工程称为全矢量角色动画。公开代码包含原创占位SVG与私有层适配数学，不包含角色图。当前checkout只有人工口播参考和占位QA证据，不能据此声明私有正片完成。

## 保持一致的四层

1. 案例语义：一轮积分游戏；A是行/数对第一项，B是列/第二项；红蓝是策略，不是人物或好坏。
2. 角色身份：人物类型可以换，A/B的讲解任务、徽记形状与收益次序不能悄悄交换。
3. 教学画面：同一桌面、同一副红蓝牌、同一张收益矩阵，知识通过对象位置/可见性/连接关系变化而展开。
4. 字幕与口播：以完整句或自然语义块为单位。显示窗包含句尾理解时间，不逐字打字，不为了追动画强迫口播加速。

## 排版和净空

设计坐标为1920×1080，4K按2倍目标像素直接绘制，不增加信息量。

- 左右安全边距84px，主内容在y=917前结束；字幕分隔线y=936。
- 顶栏、章节题、主图、底部定义、字幕为独立水平带。
- 主标题约72px，正文33px，主字幕按根配置38–48px/700（默认40px）；数对64px；常规主文字不低于27px。图形内的A/B身份徽记属于辅助文字，可更小，但旁边必须有大姓名。
- 图形与文字目标间距24px，连接线与文字框至少留8px且另计线宽。人物姓名在轮廓外，目标净空32px。
- 连接线不得为了“关联感”从文字背后穿过。线先走自己的通道，箭头停在图形边缘。原版结尾的跨字弧线已移除。
- 当前主字对底色对比约10.63:1，次要字约7.42:1。小字仍须在960×540或手机横屏小窗中看得清。
- 静止文字完全不透明；出现/退出允许短暂透明，但旧文字必须退场后，新文字才能占据同一区域。

## 动效语法

- 进入/退出使用单调的quintic smoothstep，不弹跳、不循环呼吸、不无意义缩放。
- 标题退出0.25秒，下一标题进入0.42秒，不交叉重影。
- 牌面翻转用水平尺度穿过零并切换正反面；牌背为真实SVG遮挡，不以科技锁面板表示信息未知。
- 跨轮计划：原角色持续存在，另一角色让开演示空间，红牌移动到第一轮节点，后续条件分支再出现。先显示条件，再显示应对。
- 桌面转矩阵：旧定义文字先退出；角色徽记和牌移动到行列标签；到位后网格才逐段建立，避免网格穿过运动中的姓名或旧说明。
- 读表：先提示A行，再提示B列，最后出现收益。逐格填入后保留已有数字，不整表重刷。
- 收益转复盘：同一完整矩阵缩排到右侧，左边再进入四问。不能叠两张透明表做假“丝滑”。
- 最后2.5秒保持稳定，不新增知识。

## 资产规则

`assets/*.svg` 必须是真正可编辑的路径、形状、组，不嵌入位图冒充SVG。中文和可更改姓名由渲染层使用明确SC字体覆盖。保留可定位的身体/脸/手/道具组和锚点。

角色接口使用420×500局部槽位、桌面y=480。RGBA演员通过character_adapter映射；主场景1080p rig倍率0.6，4K为1.2，因此4K并不增加原位图细节。原创SVG占位图供无私有素材时运行CI，徽记锚点(164,374)。新演员若使用不同坐标，应先适配这个接口或更新资源注册表和布局；不能直接把整身位图裁头后当成已完成动画资产。位图效果稿只用于确认风格。

## 数据到渲染

- 根 `design/scenes.json` 保存案例、名字、策略名、矩阵和默认选择；`content.json` 2.1 只声明六节教学合同与共享来源。
- `cast.json` 1.1 绑定A/B身份和资产路径，不重复显示名；台词通过 `{{A}}` / `{{B}}` / `{{red}}` / `{{blue}}` 引用共享案例。
- 根 `design/tokens.json` 是B色板、字幕字号和标题字体入口；production `tokens.json` 1.0 声明固定几何/字号/动作合同，Schema拒绝不支持的改动。复杂的场景几何在 `scenes.mjs` 手工编排。
- 根 `chapters/01-four-elements/narration/timeline.json` 同时驱动字幕和视觉事件。`start/end` 是完整显示窗，`voiceover_end` 是人工估计说完时刻，`pause_after` 已在end内。
- 内容、字幕和图形必须同源。矩阵数据不一致时QA应直接失败，不能“先渲染看看”。

此工程是有限的教学组件，不是能任意换文案的自动排版系统。改变姓名长度、章节结构、收益格数或字幕密度，必须重新排版和验收。

## 录音之后

当前173.3秒为人工参考，没有实际真人音轨。录音后先标记完整句及呼吸点，再更新每段时间与数字出现点；检查窗口是否容得下动作。不把播放器时间戳或本稿的估算当作已精确对齐的证据。

## 发布前验收

所有命令从仓库根目录执行，先按README安装依赖和字体。

1. `npm run qa:episode:content` 检查时间连续、收益语义、字体色彩、可编辑SVG和确定性。
2. `npm run qa:episode:layout -- --all-frames` 检查整个30fps时间轴的文字越界、文字重叠和连接线净空。
3. `npm run qa:episode:layout -- --all-frames --stress-cast` 用四字名字压力测试。
4. 查看至少12个关键帧与8个转场中间帧。自动路径检测不覆盖SVG内所有曲线，也不能代替视觉检查。
5. 原生1080p与4K分别渲染；编码后重新抽帧查看中文字形、表头、收益数字和细线。
6. ffprobe核对尺寸、帧率、时长、色彩标记、音轨；FFmpeg完整解码零报错。
7. 交付说明区分已完成、未检验和待用户确认；不把占位演员、手工时间轴或静态效果稿说成最终制作。

公开源码中的上述命令使用原创SVG占位演员；私有生产验证可在具备相应素材时移除占位参数。历史私有成片QA记录不随公开源码提交，应对当前checkout重新运行验证。
